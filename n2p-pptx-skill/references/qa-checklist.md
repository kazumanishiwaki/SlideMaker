# n2p-pptx QAチェックリスト

PPTX完成前・レビュー時の検証チェックリスト。  
各項目に **チェック方法**・**合格基準（数値）**・**失敗時の修正アクション** を明記する。

---

## 使い方

1. スライドを全枚数確認し、各項目を順にチェックする
2. 不合格（×）が1件でもあればリリース**禁止**
3. 不合格項目は「修正アクション」の手順で修正し、再チェックする

## カテゴリ1: ロゴ

| # | チェック項目 | チェック方法 | 合格基準 | 失敗時の修正アクション |
|---|------------|------------|---------|-------------------|
| L-01 | 本文スライドにロゴが存在する | PowerPoint でスライドパネルを1枚ずつ確認 | ロゴ画像が全本文スライドに存在する | `addLogoBlack(slide)` または `addLogoWhite(slide)` を追加 |
| L-02 | ロゴの配置座標が正しい | PPTXを開き、ロゴを選択して「図形の書式設定」→位置を確認 | x: 8.9±0.05in / y: 0.15±0.05in | pptxgenjs コードの x/y 値を修正（`addLogoBlack` の定数値を使用） |
| L-03 | ロゴのサイズが正しい | 図形の書式設定→サイズを確認 | w: 0.9±0.02in / h: 0.30±0.02in（アスペクト比3:1） | w/h を正しい値に修正。縦横比のロックを確認 |
| L-04 | 白背景に白ロゴを使っていない | スライド背景色とロゴファイル名を照合 | 白・明背景 → `symbol_black.png` / 暗・グレー背景 → `symbol_white.png` | ロゴファイルを正しいバリエーションに変更 |
| L-05 | 写真上のロゴ視認性が確保されている | 実際にPPTXを開いて目視確認 | 黒ロゴは背景明度#CCCCCC以上 / 白ロゴは背景暗度#959595以下のエリアにのみ配置 | 背景に半透明オーバーレイを追加するか、ロゴの色（黒/白）を切り替える |
| L-06 | ロゴが回転・傾斜していない | ロゴを選択→「図形の書式設定」→回転が0度であること | 回転角度: 0° | `addImage` の `rotate` プロパティを削除 |
| L-07 | ロゴの透明度が規定値内である | ロゴを選択→書式→透明度を確認 | 本文スライド: 透明度0% / 表紙透かし: 透明度70% | 本文スライドの `transparency` プロパティを削除、または `addLogoCoverWatermark` を使用 |
| L-08 | 表紙にロゴ透かしが存在する | 表紙スライドを目視確認 | `symbol_white.png` が x:6.2 y:4.0 w:3.8 h:1.25、透明度70%で右下に配置されている | `addLogoCoverWatermark(slide)` を呼び出し |
| L-09 | ロゴ隔離エリアに他要素が侵食していない | ロゴ周囲のテキスト・図形の座標を確認 | ロゴ下端(y:0.45)から0.15in以内にコンテンツがない / ロゴ左端(x:8.9)から0.15in以内に他要素がない | 侵食している要素のyまたはx座標を修正 |
| L-10 | エンドスライドのロゴは中央大サイズである | エンドスライドを目視確認 | `symbol_black.png` が x:3.5 y:2.0 w:3.0 h:0.99 で中央に配置されている | エンドスライドのロゴ配置コードを修正 |

## カテゴリ2: カラー

| # | チェック項目 | チェック方法 | 合格基準 | 失敗時の修正アクション |
|---|------------|------------|---------|-------------------|
| C-01 | 黒色の指定が `#111111` のみである | コードを `grep '212121'` で検索 | ヒット件数: 0（`#212121` が一切存在しない） | 全 `'212121'` を `N2P_COLORS.black`（`'111111'`）に置換 |
| C-02 | 白背景が `#FCFCFC` である | コードを `grep 'FFFFFF'` で検索（コピーライト・テキスト色の白は除外） | 背景色に `'FFFFFF'` が使われていない | `slide.background = { color: 'FFFFFF' }` を `{ color: 'FCFCFC' }` に修正 |
| C-03 | 本文テキスト色が `#434343` である | コードの `color` 指定を確認 | 本文テキストの color 値: `'434343'` | `color: '333333'` 等を `N2P_COLORS.bodyText` に修正 |
| C-04 | フッターテキスト色が `#999999` である | フッター関連コードを確認 | コピーライト・ページ番号の color: `'999999'` | `addFooter` 関数内の定数を確認 |
| C-05 | フッター軸線色が `#CCCCCC` である | フッター軸線の `line.color` を確認 | `line: { color: 'CCCCCC', width: 0.5 }` | 軸線の color を `'CCCCCC'` に修正 |
| C-06 | イエロー使用面積が10%以下である | PPTX全スライドを目視確認 | 1スライドあたりのイエロー使用面積 ≤ スライド全面積の10%（≈ 5.625 sq.in） | イエロー背景のサイズを縮小、または強調箇所をキーワード単位に絞る |
| C-07 | アクセントカラーが1色以内である | スライド全体を目視確認 | 強調色はイエロー（`#F4F400` / `#E8E800`）のみ。他の原色は使われていない | 余分なアクセントカラーをグレー系または削除に変更 |
| C-08 | コードに `#212121` が存在しない | `grep -r '212121'` でプロジェクト全体を検索 | ヒット件数: 0 | 全件を `'111111'`（または用途に応じた正しい色）に修正 |

## カテゴリ3: タイポグラフィ

| # | チェック項目 | チェック方法 | 合格基準 | 失敗時の修正アクション |
|---|------------|------------|---------|-------------------|
| T-01 | フォントがNoto Sans JPのみである | コードの `fontFace` 指定を全件確認 | 全テキストの `fontFace: 'Noto Sans JP'` | Meiryo / Yu Gothic 等を `'Noto Sans JP'` に変更 |
| T-02 | 本文フォントサイズが11ptである | 本文テキストのコードを確認 | `fontSize: 11`（`addBody` のデフォルト） | フォントサイズを 11 に修正 |
| T-03 | 大見出しが16pt Boldである | `addH1` の呼び出しを確認 | `fontSize: 16, bold: true` | `addH1` を使用していない箇所を修正 |
| T-04 | 中見出しが13pt Boldである | `addH2*` の呼び出しを確認 | `fontSize: 13, bold: true` | `addH2Dark` / `addH2Light` / `addH2Underline` を使用 |
| T-05 | 本文行間が1.15である | 本文テキストの `lineSpacingMultiple` を確認 | `lineSpacingMultiple: 1.15` | `addBody` 関数を使用（デフォルトで設定済み） |
| T-06 | 表紙タイトルが28pt Boldである | 表紙スライドコードを確認 | `fontSize: 28, bold: true` | 表紙タイトルのサイズを修正 |
| T-07 | フッターテキストが8-9ptである | `addFooter` のコードを確認 | コピーライト: `fontSize: 8` / ページ番号: `fontSize: 9` | `addFooter` 関数の定数を確認 |
| T-08 | 全角数字を使っていない | スライドテキストを目視確認 | 数字はすべて半角（1234567890） | 全角数字（１２３）を半角に変換 |
| T-09 | 見出しがBoldである | 全見出しテキストオプションを確認 | 大見出し・中見出しすべてに `bold: true` | `bold: false` または `bold` 未指定の見出しを修正 |

## カテゴリ4: マージン・レイアウト

| # | チェック項目 | チェック方法 | 合格基準 | 失敗時の修正アクション |
|---|------------|------------|---------|-------------------|
| M-01 | 本文左端がマージン内である | コンテンツの `x` 座標を確認 | すべてのコンテンツ: x ≥ 0.48in | x が 0.48 未満の要素を x: 0.48 以上に修正 |
| M-02 | コンテンツ右端がマージン内である | コンテンツの `x + w` 値を確認 | すべてのコンテンツ: x + w ≤ 9.52in | w を縮小するか x を右にずらす |
| M-03 | コンテンツがフッター領域に侵食していない | コンテンツの `y + h` 値を確認 | 本文コンテンツ下端: y + h ≤ 5.20in | コンテンツの高さを縮小するか y 座標を上にずらす |
| M-04 | コンテンツが上端マージン内である | コンテンツの `y` 座標を確認（見出し除く） | コンテンツ（見出し以外）: y ≥ 0.197in | y が 0.197 未満の要素を修正 |
| M-05 | カラム間マージンが確保されている | 複数カラムレイアウトの座標を確認 | カラム間間隔 ≥ 0.30in（推奨 0.35in） | カラム幅を縮小してギャップを確保 |

## カテゴリ5: フッター

| # | チェック項目 | チェック方法 | 合格基準 | 失敗時の修正アクション |
|---|------------|------------|---------|-------------------|
| F-01 | 本文スライド全枚にフッターがある | 全スライドを目視確認 | 表紙・中表紙・エンド以外の全スライドにフッターが存在する | `addFooter(slide, pageNum)` を追加 |
| F-02 | フッター軸線の座標が正しい | `addFooter` のコードを確認 | x: 0.28 / y: 5.28 / w: 9.44 / 線太さ: 0.5pt | `addFooter` の定数を修正 |
| F-03 | コピーライト文字列が正確である | PPTX上でフッターテキストを確認 | `© NONAME Produce Inc.` （スペース・大文字・表記が完全一致） | 誤字・表記違いを修正 |
| F-04 | ページ番号が半角数字である | 全スライドのページ番号を目視確認 | 半角数字のみ（`1` `2` `3`…）。全角（１）は不可 | `String(pageNum)` の値を確認し半角に修正 |
| F-05 | ページ番号が右寄せである | ページ番号テキストオプションを確認 | `align: 'right'` | `align: 'right'` を追加 |
| F-06 | ページ番号が連続昇順である | 全スライドのページ番号を目視確認 | 1, 2, 3 … と連続して昇順になっている | 重複・欠番・逆順がないか確認し修正 |
| F-07 | 表紙にフッターがない | 表紙スライドを確認 | 軸線・コピーライト・ページ番号のいずれも存在しない | 表紙で `addFooter` を呼んでいる箇所を削除 |
| F-08 | エンドスライドにフッターがない | エンドスライドを確認 | 軸線・コピーライト・ページ番号のいずれも存在しない | エンドスライドで `addFooter` を呼んでいる箇所を削除 |

## カテゴリ6: 見出し

| # | チェック項目 | チェック方法 | 合格基準 | 失敗時の修正アクション |
|---|------------|------------|---------|-------------------|
| H-01 | 大見出しに左ダッシュ線がある | 全本文スライドを目視確認 | 見出しテキストの左に水平線が存在する | `addH1(slide, text)` を使用（ダッシュ線が自動追加される） |

| H-05 | 1スライドに大見出しが1つである | スライドごとに `addH1` の呼び出し数を確認 | 1スライドにつき `addH1` は1回のみ | 複数の大見出しがある場合はスライドを分割する |

## Bash確認コマンド集

pptxgenjsのJSコードを検索するときに使用するコマンド例。

```bash
# NG色値の混入チェック
grep -rn '212121' ./src/

# 企業名NG表記チェック
grep -rni 'N2P\|nonameproduce\|noname produce\|株式会社 n2p' ./src/

# FFFFFF（純白背景）チェック
grep -n "'FFFFFF'" ./src/slides/*.js

# addFooter 呼び出し漏れスライドの概算確認（呼び出し数をカウント）
grep -c 'addFooter' ./src/slides/*.js

# addLogoBlack / addLogoWhite 呼び出し漏れ確認
grep -c 'addLogo' ./src/slides/*.js
```
