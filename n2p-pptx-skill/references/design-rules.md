## 2. マージンと余白

**基準: 上下左右 0.5cm（約0.197 in）**

どんなにコンテンツが多くても、このマージン内にコンテンツ要素が侵入しないこと。

### 座標導出式

| 要素 | 導出式 | 値 |
|------|--------|-----|
| コンテンツ左端 x | 0.197 + 0.14 (線分幅) | 0.34 in |
| 大見出しテキスト x | 0.05 (線開始) + 0.45 (線長) + 0.05 (間隔) | 0.55 in |
| 本文テキスト x | 見出しと揃える | 0.48 in |
| コンテンツ右端上限 x+w | 10 − 0.4 (右マージン) | 9.60 in |
| コンテンツ上端 y | 0.197 (マージン) | 0.20 in |
| コンテンツ下端上限 y+h | 5.625 − 0.425 (フッター) | 5.20 in |

- **2段組**: 要素間に最低 1 cm（0.394 in）のギャップを設ける
- 大見出しテキストボックスの端と本文ボックスの端はぴったり隣接させる
- 本文ボックスは見出しよりわずかに右にインデントし、視覚的階層感を出す

## 3. カラーパレット

n2pのデザインは**極力シンプル**に。使用色は「地の文 + 1色」が基本原則。VIガイドライン準拠の色値を以下に定める。**黒は必ず `#111111`（`#212121` は使用禁止）**。

| トークン名 | カラーコード | 主な用途 |
|-----------|------------|--------|
| `n2p_black` | `#111111` | 主見出し・ロゴ・強調テキスト |
| `n2p_white` | `#FCFCFC` | 本文スライド背景・白テキスト |
| `n2p_dark_gray` | `#676A6D` | サブ見出し・中見出し帯文字 |
| `n2p_mid_gray` | `#929699` | 中位テキスト・補足情報 |
| `n2p_lite_gray` | `#E6EBED` | 目次背景・中見出し帯・薄い背景 |
| `n2p_yellow_dark` | `#E8E800` | 小面積強調（文字ハイライト） |
| `n2p_yellow_light` | `#F4F400` | 大面積強調（背景ハイライト） |
| `body_gray` | `#434343` | 本文テキスト・通常テキスト |
| `n2p_link` | `#4285F4` | リンク・URL |
| `n2p_teal` | `#0097A7` | リンク代替・キャンペーン要素 |
| `divider_gray` | `#CCCCCC` | フッター軸線・区切り線 |
| `footer_gray` | `#999999` | フッターテキスト・日付・補足 |
| `cover_bg` | `#D7DEE2` | 表紙・中表紙背景 |
| `corp_header` | `#1B2A4A` | 会社概要ヘッダー背景 |

### イエロー使用ルール

- 使用量は**スライド全体の10%以下**に抑える
- **小面積（文字・アイコン周辺）**: `#E8E800`（濃いイエロー）を使用
- **大面積（帯・背景ブロック）**: `#F4F400`（薄いイエロー）を使用
- pptxgenjsのhighlight指定では `'FFFF00'` に近似（ライブラリ制約）
- イエロー以外の差し色（赤・青系）はアクセントに使わない

## 4. フォント

### Web推奨書体

| 役割 | 欧文 | 和文 |
|------|------|------|
| 標準テキスト | Helvetica Neue Light / Regular / Bold | Noto Sans JP Light / Regular / Bold |
| 代替（Helvetica不可時） | Open Sans（Google Fonts） | Noto Sans JP |

### 印刷・グラフィック推奨書体

| 役割 | 欧文 | 和文 |
|------|------|------|
| 標準テキスト | Helvetica Neue Light / Regular / Bold | 中ゴシック BBB |
| 複数ウェイトが必要な場合 | Helvetica Neue | Noto Sans JP |

**合成フォント（和欧混植）の重要設定**: Helveticaのサイズを **105% に設定**すること（VIガイドライン指定）。

| 本文 | Noto Sans JP | 11 pt | Regular | `#434343` |

| 表紙宛名 | Noto Sans JP | 14 pt | Regular | `#111111` |
| 表紙日付 | Noto Sans JP | 11 pt | Regular | `#999999` |

| フッターコピーライト | Noto Sans JP | 8 pt | Regular | `#999999` |
| フッターページ番号 | Noto Sans JP | 9 pt | Regular | `#999999` |

## 5. 大見出しルール（h1）

- 16 pt、太字、色 `#111111`
- **左側に水平ダッシュ線を必ずつける**。これがn2p提案資料の最も特徴的なデザイン要素
- 線の仕様: 色 `#111111`、太さ 1 pt、水平方向に 0.45 in（約 1.14 cm）
- テキストの左にダッシュ線が水平に伸びる形（「——見出しテキスト」のように見える）

### 座標導出式

| 要素 | 導出式 | 値 |
|------|--------|-----|
| 線 x 開始 | 左マージン 0.197 − 0.15 | 0.05 in |
| 線 y | h1テキスト中心 0.35 | 0.35 in |
| 線 w | 固定値 | 0.45 in |
| テキスト x | 線x + 線w + 0.05 間隔 | 0.55 in |
| テキスト y | 上マージン 0.197 ≈ | 0.14 in |
| テキスト w | コンテンツ右端 9.6 − 0.55 | 7.50 in |
| テキスト h | 行高 | 0.42 in |

pptxgenjsでの実装:
```js
// 大見出しの左ダッシュ線
slide.addShape('line', {
  x: 0.05, y: 0.35,
  w: 0.45, h: 0.0,
  line: { color: '111111', width: 1 }
});
// 大見出しテキスト
slide.addText('見出しテキスト', {
  x: 0.55, y: 0.14,
  w: 7.50, h: 0.42,
  fontSize: 16, bold: true, color: '111111',
  fontFace: 'Noto Sans JP',
  valign: 'middle'
});
```

## 6. 中見出しバリエーション（h2）

中見出し（セクション内の小区分）には4つのバリエーションがある。用途に応じて選ぶ。

### バリエーション1: ダーク帯（白テキスト）

- 用途: 「目標」「ターゲット」など、項目ラベルとして使う場合
- 背景: `#434343`、テキスト: `#FFFFFF`、角丸: 0.02 in

```js
const yPos = 0.6; // スライド内の縦位置
// 帯（角丸長方形）
slide.addShape('roundRect', {
  x: 0.48, y: yPos,
  w: 2.50, h: 0.35,
  fill: { color: '434343' },
  rectRadius: 0.02,
  line: { color: '434343', width: 0 }
});
// 白テキスト
slide.addText('中見出し', {
  x: 0.48, y: yPos,
  w: 2.50, h: 0.35,
  fontSize: 13, bold: true, color: 'FFFFFF',
  fontFace: 'Noto Sans JP',
  align: 'center', valign: 'middle'
});
```

### バリエーション2: ライトグレー帯 + 丸ドット

- 用途: 中程度の区切り・複数項目の並列表示
- 背景: `#E6EBED`、テキスト: `#111111`、左端に黒丸ドット（直径 0.1 in）

```js
const yPos = 1.0;
// ライトグレー帯
slide.addShape('rect', {
  x: 0.48, y: yPos,
  w: 9.04, h: 0.35,
  fill: { color: 'E6EBED' },
  line: { color: 'E6EBED', width: 0 }
});
// 左端の丸ドット（n2p_black）
slide.addShape('ellipse', {
  x: 0.52, y: yPos + 0.125,
  w: 0.10, h: 0.10,
  fill: { color: '111111' },
  line: { color: '111111', width: 0 }
});
// テキスト
slide.addText('中見出し', {
  x: 0.68, y: yPos,
  w: 8.60, h: 0.35,
  fontSize: 13, bold: true, color: '111111',
  fontFace: 'Noto Sans JP',
  valign: 'middle'
});
```

### バリエーション3: グラデーション下線 + 丸ドット

- 用途: 軽い区切り・細かいセクション分け
- テキスト: `#111111`、テキスト下にグレーのグラデーション線（左 `#676A6D` → 右 `#FCFCFC`）
- 線の右端に灰丸ドット（`#929699`、直径 0.12 in）

```js
const yPos = 1.5;
// テキスト
slide.addText('中見出し', {
  x: 0.48, y: yPos,
  w: 9.04, h: 0.35,
  fontSize: 13, bold: true, color: '111111',
  fontFace: 'Noto Sans JP',
  valign: 'middle'
});
// グラデーション下線（矩形で擬似表現）
slide.addShape('rect', {
  x: 0.48, y: yPos + 0.36,
  w: 8.90, h: 0.02,
  fill: { type: 'gradient', stops: [
    { position: 0, color: '676A6D' },
    { position: 100, color: 'FCFCFC' }
  ]},
  line: { width: 0 }
});
// 右端の丸ドット（mid_gray）
slide.addShape('ellipse', {
  x: 9.26, y: yPos + 0.295,
  w: 0.12, h: 0.12,
  fill: { color: '929699' },
  line: { width: 0 }
});
```

### バリエーション4: 画像背景 + 半透明レイヤー

- 用途: ビジュアル重視のセクション区切り・インパクトある小区分
- 背景画像の上に半透明白レイヤー（透明度 40%）を重ね、その上に濃色テキスト

```js
const yPos = 2.0;
const imgPath = 'path/to/section-image.jpg';
// 背景画像
slide.addImage({
  path: imgPath,
  x: 0.48, y: yPos,
  w: 9.04, h: 0.50
});
// 半透明白レイヤー（透明度 40% → transparency: 40）
slide.addShape('rect', {
  x: 0.48, y: yPos,
  w: 9.04, h: 0.50,
  fill: { color: 'FCFCFC', transparency: 40 },
  line: { width: 0 }
});
// テキスト（コントラスト確保のため濃色）
slide.addText('中見出し', {
  x: 0.60, y: yPos,
  w: 8.80, h: 0.50,
  fontSize: 13, bold: true, color: '111111',
  fontFace: 'Noto Sans JP',
  valign: 'middle'
});
```

## 7. 小見出しルール（h3）

## 8. テキスト強調

- **通常の強調**: 太字にする
- **さらに強い強調**: 黄色ハイライト（ラインマーカー）を引く
  - 小面積（文字周辺）: `#E8E800`（濃いイエロー）
  - 大面積（行全体・ブロック背景）: `#F4F400`（薄いイエロー）
- **使用量は全体の10%以下**。多用は厳禁
- 強調色はイエロー系のみ。赤・オレンジ・青系のハイライトは使わない

pptxgenjsでの黄色ハイライト実装:
```js
slide.addText([
  { text: '通常テキスト。', options: { fontSize: 11, color: '434343' } },
  {
    text: '重要な強調テキスト',
    options: {
      fontSize: 11, color: '111111', bold: true,
      highlight: 'FFFF00'   // pptxgenjs制約: 最近似色を指定
    }
  },
  { text: 'の続きテキスト。', options: { fontSize: 11, color: '434343' } }
], {
  x: 0.48, y: yPos,
  w: 9.04, h: 0.40,
  fontFace: 'Noto Sans JP'
});
```

## 9. ロゴ配置

### ロゴ隔離エリア（VIガイドライン厳守）

- 隔離エリア = ロゴ高さ（H）の **50%** を四方に確保
- 隔離エリア内に他の要素を一切配置しないこと
- 最小使用サイズ: **32 px（Web）/ 10 mm（Print）**

### 写真上でのロゴ配置

- **黒ロゴ**: 背景明度が `#CCCCCC`（RGB 204,204,204）以上の明るい場所のみ使用可
- **白ロゴ**: 背景暗度が `#959595`（RGB 149,149,149）以下の暗い場所のみ使用可
- 視認性が確保できない場合はフィルターを重ねるか、配置位置を変更すること

### 5シーン別の配置仕様

| シーン | ファイル | x | y | w | h | 透明度 |
|--------|---------|---|---|---|---|--------|
| 本文スライド（白背景） | `symbol_black.png` | 8.90 in | 0.15 in | 0.90 in | 0.30 in | 0% |
| 中表紙（グレー背景） | `symbol_white.png` | 8.90 in | 0.15 in | 0.90 in | 0.30 in | 0% |
| 表紙（透かし） | `symbol_white.png` | 6.50 in | 4.00 in | 3.50 in | — | 70% |
| 会社概要（ダークヘッダー内） | `symbol_white.png` | ヘッダー内右寄せ | — | 1.20 in | — | 0% |
| エンドスライド | `symbol_black.png` | 中央揃え | — | 2.00 in | — | 0% |

**本文ロゴの座標導出式**:
- x = スライド幅 10 − 右マージン 0.4 − ロゴ幅 0.9 = 8.70 → 視覚調整で **8.90**
- y = 上マージン 0.197 ≈ **0.15**
- h = ロゴ原寸比率 2000:657 → w 0.90 × (657/2000) = **0.296 ≈ 0.30**

### ロゴ使用禁止パターン（VIガイドライン）

回転・傾斜、アスペクト比変更、指定外カラー、半透明化（表紙透かし以外）、ロゴへの装飾追加（影・線・パターン）、アウトライン化、要素の分解配置は全て禁止。

## 10. フッター

表紙・中表紙・エンドスライド以外の全スライドにフッターを配置する。

### フッターの構成

1. **軸線**: スライド下部の水平細線（色 `#CCCCCC`、太さ 0.5 pt）
2. **コピーライト**: 線の下、左寄せ「© NONAME Produce Inc.」（8 pt、`#999999`）
3. **ページ番号**: 線の下、右寄せ（9 pt、`#999999`）

### 座標導出式

| 要素 | 導出式 | 値 |
|------|--------|-----|
| 軸線 x 開始 | 左マージン 0.197 + 調整 0.083 | 0.280 in |
| 軸線 y | スライド高 5.625 − フッター高 0.345 | 5.280 in |
| 軸線 w | 右端 9.720 − 左端 0.280 | 9.440 in |
| コピーライト x | 軸線 x と揃える | 0.280 in |
| コピーライト y | 軸線 y + 0.020 | 5.300 in |
| ページ番号 x | 右端 9.720 − テキスト幅 0.520 | 9.200 in |
| ページ番号 y | コピーライトと揃える | 5.300 in |

pptxgenjsでの実装:
```js
function addFooter(slide, pageNum) {
  // 軸線
  slide.addShape('line', {
    x: 0.28, y: 5.28,
    w: 9.44, h: 0.0,
    line: { color: 'CCCCCC', width: 0.5 }
  });
  // コピーライト
  slide.addText('© NONAME Produce Inc.', {
    x: 0.28, y: 5.30,
    w: 3.00, h: 0.25,
    fontSize: 8, color: '999999',
    fontFace: 'Noto Sans JP'
  });
  // ページ番号
  slide.addText(String(pageNum), {
    x: 9.20, y: 5.30,
    w: 0.52, h: 0.25,
    fontSize: 9, color: '999999',
    fontFace: 'Noto Sans JP',
    align: 'right'
  });
}
```

## 11. 線と図形

- **線の太さ基本**: 1 pt
- **強調時上限**: 最大 3 pt
- **フッター軸線**: 0.5 pt（細め固定）
- **大見出し左ダッシュ線**: 1 pt
- 図形は塗りなし（アウトラインのみ）を基本とする
- 吹き出し・爆発型・装飾的な既製図形の使用は避ける
- 色は `#111111`（線）または `#CCCCCC`（軽い区切り）を標準とする

---

## 12. 矢印

### 使用する矢印（OK）

- 細い線の矢印（線端に小さな矢じり、1 pt、色 `#111111`）
- 線なしの小さな三角形（▷ ▶、サイズ 0.1 in 程度）
- 上下展開の流れを示す波線的な矢印

### 使用しない矢印（NG）

- 装飾的な太矢印（3 pt 超）
- ポップな印象・カラフルな矢印
- 大型のベタ塗り矢印・記号（PowerPoint既製の派手な矢印図形）

## 13. 表実装ガイド

n2p提案資料の表は整然・シンプルさを最優先とする。

### 標準仕様

| 要素 | 仕様 |
|------|------|
| 枠線 | 1 pt、`#111111` |
| ヘッダー背景 | `#E6EBED`（n2p_lite_gray） |
| ヘッダーテキスト | 12 pt、Bold、`#111111` |
| ボディ背景（奇数行） | `#FCFCFC` |
| ボディ背景（偶数行） | `#F5F7F8`（E6EBEDの薄め近似） |
| ボディテキスト | 11 pt、Regular、`#434343` |
| セルパディング | 上下 0.05 in、左右 0.10 in |
| セル間隔 | 0.05 in |
| 最小行高 | 0.30 in |

pptxgenjsでの実装例:
```js
const tableData = [
  [
    { text: '項目', options: { bold: true, color: '111111', fill: 'E6EBED' } },
    { text: '内容', options: { bold: true, color: '111111', fill: 'E6EBED' } },
    { text: '備考', options: { bold: true, color: '111111', fill: 'E6EBED' } }
  ],
  [
    { text: '項目A', options: { color: '434343' } },
    { text: '内容テキスト', options: { color: '434343' } },
    { text: '—', options: { color: '929699' } }
  ]
];
slide.addTable(tableData, {
  x: 0.48, y: 0.70,
  w: 9.04,
  fontSize: 11,
  fontFace: 'Noto Sans JP',
  border: { type: 'solid', pt: 1, color: '111111' },
  rowH: 0.35,
  align: 'left',
  valign: 'middle'
});
```

### 注意事項

- 表全体の横幅はコンテンツエリア（9.04 in）に収める
- ヘッダー行は必ず `#E6EBED` 背景を使用する
- セル内テキストが溢れる場合はフォントサイズを 10 pt → 9 pt → 8 pt の順で縮小する（8 pt 未満は禁止）
- 強調セルには `#F4F400` 背景を使用可。ただし使用量 10% 以下を維持

## 14. フロー図実装ガイド

キャンペーンフローやユーザー旅程図の実装基準を定める。

### 矢印・線の仕様

| 要素 | 仕様 |
|------|------|
| フロー矢印線 | 1 pt、`#111111` |
| フロー矢印頭 | 小さな三角形、サイズ 0.06 in |
| 補助線（点線） | 0.75 pt、`#929699`、破線 |

### 図形の仕様

| 要素 | 仕様 |
|------|------|
| プロセス四角形 | 枠線 1 pt `#111111`、背景 `#FCFCFC`、角丸 0.02 in |
| 判断菱形 | 枠線 1 pt `#111111`、背景 `#FCFCFC` |
| 開始・終了楕円 | 枠線 1 pt `#111111`、背景 `#E6EBED` |
| 図形内テキスト | 11 pt、Regular、`#434343`（最小 8 pt）|
| 図形間隔 | 0.30 〜 0.50 in |

### 配置ルール

- 図全体の端とスライド枠のマージンは 0.5 cm（0.197 in）以上を確保
- 図形内テキストが 2 行以上になる場合は図形高を 0.05 in 単位で拡大
- 色強調が必要な図形は背景に `#F4F400` を使用可（使用量 10% 以下厳守）

## 15. 素材ガイドライン

### 写真

**推奨**:
- 十分な解像度・高画質のもの（最低 72 dpi / 投影用）
- 自然なシチュエーション・リアルな場面
- 透かし（ウォーターマーク）が入っていないもの
- 色調が資料全体と調和するもの

**非推奨**:
- 低解像度・ぼやけた写真
- 作られたポーズや背景切り抜きなど不自然なカット
- 透かしが残っているもの
- フリー素材サイトの過度に使われた典型的な写真

### イラスト・アイコン

**推奨**:
- アイソメトリクス（等角投影）などビジネスライクなもの
- 色味を抑えたシンプルなフラットデザイン
- 線の太さが均一な単色・2色程度のもの

**非推奨**:
- いらすとや・過度にポップなクリップアート
- 過剰な色数・渐変の複雑なイラスト
- ソースが即座に特定できる汎用素材

## 16. 非推奨デザイン

### 色の多用

使用色は「地の文 + 1色（イエロー系）」が基本。複数の派手な差し色（赤・緑・橙・紫など）を同一スライドに使わない。イエロー以外のカラーをアクセントにしない。

### 図形の多用

吹き出し・爆発型・星型など装飾的な既製図形を使わない。PowerPoint付属の派手な SmartArt は原則禁止。シンプルな矩形・楕円・線のみで構成する。

### 不適切な文字装飾

- 意味段落でない場所での改行
- 中間色 + 枠線の組み合わせ（読みにくい）
- 全角数字・全角英字の混在
- フォントサイズの極端な混在（同一テキストボックス内で 6 pt 差以上）

### ロゴの不正使用

- ロゴの回転・傾斜・変形
- 指定外の色でのロゴ使用
- 隔離エリア内への要素の侵入
- 最小サイズ（Web 32 px / Print 10 mm）以下での使用

### 企業名表記NG例

| NG表記 | 理由 |
|--------|------|
| `N2P` | 大文字混在は禁止 |
| `株式会社 n2p` | 法人名に小文字 n2p は使用不可 |
| `nonameproduce` | 全小文字・結合表記は禁止 |
| `noname produce` | 分割小文字表記は禁止 |
| `株式会社 N2P` | 大文字混在は禁止 |

**正式な企業名表記（3パターン）**:
1. `株式会社 NONAME Produce`
2. `NONAME Produce`
3. `n2p`

初出時の略称表記例: `NONAME Produce（以下 n2p）`、`NONAME Produce（n2p）`
