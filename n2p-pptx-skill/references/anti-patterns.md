# n2p-pptx アンチパターン集（NG例）

このドキュメントはn2pブランドガイドライン違反、およびデザイン品質を損なうパターンをカテゴリ別に整理する。  
各項目には **Why（理由）** と **Fix（正しい対処）** を明記する。

---

## 1. カラー違反

### 1-1. ブラックに `#111111` 以外を使う

| 項目 | 内容 |
|------|------|
| **NG** | `color: '212121'` / `color: '000000'` / `color: '333333'` |
| **Why** | VIガイドラインは n2p ブランドの黒を `#111111` と厳密に定義している。`#212121` は旧バージョンの誤った実装値であり、現行VIに違反する |
| **Fix** | `color: N2P_COLORS.black` （= `'111111'`）を使う。定数 `N2P_COLORS` を必ず参照すること |

### 1-2. 背景白に純白 `#FFFFFF` を使う

| 項目 | 内容 |
|------|------|
| **NG** | `slide.background = { color: 'FFFFFF' }` |
| **Why** | VIガイドラインの白は `#FCFCFC`（わずかにオフホワイト）。純白は印刷時に紙と区別がつかなくなるほか、ブランド定義から外れる |
| **Fix** | `slide.background = { color: N2P_COLORS.white }` （= `'FCFCFC'`） |

### 1-3. アクセントカラーを2色以上使う

| 項目 | 内容 |
|------|------|
| **NG** | イエロー `#F4F400` とブルー `#4285F4` を並べて強調に使う / スライドに3色以上の目立つ色が混在する |
| **Why** | n2p のカラールールは「ベース（白・黒・グレー）+ アクセント1色」が基本。複数のアクセントカラーが混在するとブランドの統一感が崩れる |
| **Fix** | 強調色は `#F4F400`（イエロー）1色のみ。リンク色 `#4285F4` は補助的に使えるが、強調目的には使わない |

### 1-4. イエローの使用面積が10%を超える

| 項目 | 内容 |
|------|------|
| **NG** | タイトル全体・大きなボックス全面・多数の箇条書き行に一括してイエロー背景を設定する |
| **Why** | VIガイドラインは「イエローはスライド全体の10%以下」と明示。大面積のイエローは威圧感・安っぽさの原因となる |
| **Fix** | イエローはキーワード単語単位・ハイライト1〜3箇所など「小面積の強調」にとどめる。大面積にはグレー帯を使う |

### 1-5. 派手な原色・蛍光色を多用する

| 項目 | 内容 |
|------|------|
| **NG** | 赤・緑・オレンジ・ビビッドなピンクなど原色系をデザインの主軸に使う |
| **Why** | n2p のデザインコンセプトは「シンプルで洗練された」。原色の多用はブランドイメージと相反する |
| **Fix** | 案件固有のブランドカラーが必要な場合でも、使用箇所を「表紙タイトル・強調箇所・特定スライドのアクセントに限定」し、全体の調和を保つ |

### 1-6. 本文テキストの色に `#434343` 以外を使う

| 項目 | 内容 |
|------|------|
| **NG** | `color: '333333'` / `color: '555555'` / `color: N2P_COLORS.black`（見出しと同じ黒）を本文に使う |
| **Why** | `#434343` は本文の視認性と柔らかさのバランスをとった実装慣習値。見出し（`#111111`）と本文を意図的に差別化することで階層を表現している |
| **Fix** | `color: N2P_COLORS.bodyText`（= `'434343'`）を使う |

## 2. タイポグラフィ違反

### 2-1. 全角数字を本文・データ表示に使う

| 項目 | 内容 |
|------|------|
| **NG** | 「１２月」「３，０００万円」「１５名」のように全角数字を使う |
| **Why** | n2p デザインルールは半角数字を標準とする。全角数字は可読性が低く、欧文フォント（Helvetica Neue）との混植でも崩れる |
| **Fix** | すべての数字は半角で記載。「12月」「3,000万円」「15名」 |

### 2-2. 見出しに Regular ウェイトを使う

| 項目 | 内容 |
|------|------|
| **NG** | `bold: false` のまま見出しテキストを追加する |
| **Why** | 見出し（大見出し16pt / 中見出し13pt）はすべて Bold が前提。Regular の見出しは視覚的な階層が失われ、本文と区別がつかなくなる |
| **Fix** | `addH1` / `addH2Dark` / `addH2Light` / `addH2Underline` を使う。これらは `bold: true` が内包されている |

### 2-3. 行間を `1.0` や `1.5` に設定する

| 項目 | 内容 |
|------|------|
| **NG** | `lineSpacingMultiple: 1.0`（詰めすぎ）/ `lineSpacingMultiple: 1.5`（空きすぎ） |
| **Why** | n2p の本文行間は `1.15` に統一。1.0は文字が密集して読みにくく、1.5はスライド内の情報量が減る |
| **Fix** | `addBody` 関数を使う（デフォルトで `lineSpacingMultiple: 1.15` が設定される） |

### 2-4. フォントをNoto Sans JP以外に設定する

| 項目 | 内容 |
|------|------|
| **NG** | `fontFace: 'Meiryo'` / `fontFace: 'Yu Gothic'` / `fontFace: 'HiraKakuPro-W3'` / `fontFace: 'Arial'` |
| **Why** | すべてのテキストはNoto Sans JP（Light / Regular / Bold）で統一する。異なるフォントはブランド統一を破壊する |
| **Fix** | `fontFace: 'Noto Sans JP'` を全テキストに明示的に指定する |

### 2-5. フォントサイズ階層を無視する

| 項目 | 内容 |
|------|------|
| **NG** | 大見出しを14ptにする / 本文を13ptにする / フッターを11ptにする |
| **Why** | n2p の階層は「表紙タイトル28pt / 大見出し16pt / 中見出し13pt / 本文11pt / フッター8-9pt」と厳格に定義されている |
| **Fix** | 各要素のサイズは仕様値に従う。`addH1` / `addH2*` / `addBody` / `addFooter` 関数を使えば自動的に正しいサイズが適用される |

## 3. ロゴ違反

### 3-1. ロゴを回転・傾斜させる

| 項目 | 内容 |
|------|------|
| **NG** | `rotate: 45` などでロゴを傾ける / デコレーション目的で斜め配置する |
| **Why** | VIガイドライン厳禁事項。ロゴの回転・傾斜はブランドアイデンティティを破壊する |
| **Fix** | ロゴは常に水平・正位置で使用する。`addLogoBlack` / `addLogoWhite` を使えば安全 |

### 3-2. ロゴの縦横比を変更する

| 項目 | 内容 |
|------|------|
| **NG** | `w: 0.9, h: 0.5`（意図的または意図せず縦横比を変更する） |
| **Why** | VIガイドライン厳禁事項。縦横比の変更はロゴを歪め、ブランドの信頼性を損なう |
| **Fix** | 標準サイズ `w: 0.9, h: 0.30`（アスペクト比3:1）を維持する。サイズ変更時は比率を保つ |

### 3-3. 写真上で低コントラストになる配置をする

| 項目 | 内容 |
|------|------|
| **NG** | 明るい写真（#CCCCCC以上の明度）に白ロゴを配置する / 暗い写真（#959595以下の暗度）に黒ロゴを配置する |
| **Why** | ロゴが背景に埋もれて視認不能になる。VIガイドラインは黒ロゴの使用可能条件を「背景明度 #CCCCCC 以上」、白ロゴを「背景暗度 #959595 以下」と定義している |
| **Fix** | 黒ロゴ → 明るい背景のみ / 白ロゴ → 暗い背景のみ。迷う場合は写真にフィルターを重ねてコントラストを調整する |

### 3-4. 規定以外の透明度をロゴに設定する

| 項目 | 内容 |
|------|------|
| **NG** | `transparency: 30` / `transparency: 50` を本文スライドのロゴに設定する |
| **Why** | VIガイドライン厳禁事項。透明度変更が許可されているのは表紙透かし（`transparency: 70`）のみ |
| **Fix** | 本文スライドのロゴに `transparency` プロパティを設定しない。表紙透かしは `addLogoCoverWatermark` を使う |

### 3-5. ロゴの隔離エリアを侵食する他要素を配置する

| 項目 | 内容 |
|------|------|
| **NG** | ロゴ（x:8.9, y:0.15, w:0.9, h:0.30）の周囲 h×0.5（= 0.15in）以内にテキスト・図形を配置する |
| **Why** | VIガイドラインはロゴ高さの50%を四方の隔離エリアとして確保することを義務付けている |
| **Fix** | ロゴの下端（y: 0.45）より下の要素は y: 0.60 以降に配置する。右端（x: 9.80）には他要素を配置しない |

### 3-6. ロゴにアウトライン・装飾を追加する

| 項目 | 内容 |
|------|------|
| **NG** | ロゴ画像に影（`shadow`）を設定する / ロゴに枠線を付ける / ロゴ画像を別ソフトで加工してアウトライン化する |
| **Why** | VIガイドライン厳禁事項。装飾追加はロゴの純粋性を損なう |
| **Fix** | ロゴは `addImage` でそのまま配置するだけ。加工・装飾は一切行わない |

## 4. レイアウト違反

### 4-1. マージン（0.5cm = 0.197in）を無視する

| 項目 | 内容 |
|------|------|
| **NG** | `x: 0.0` / `x: 0.1` のようにマージン内にコンテンツを配置する / コンテンツ右端が `x: 9.8` を超える |
| **Why** | 全スライドの上下左右マージンは 0.5cm（≈ 0.197in）。マージン違反はコンテンツが切れて見える |
| **Fix** | コンテンツの左端は `x: 0.48` 以上、右端は `x + w ≤ 9.52` になるよう管理する。フッター領域（y: 5.2以降）にもコンテンツを配置しない |

### 4-2. 大見出しの左ダッシュ線を省略する

| 項目 | 内容 |
|------|------|
| **NG** | `slide.addText(heading, { x: 0.55, y: 0.14, ... })` だけで左線を描かない |
| **Why** | n2p 提案資料の最も特徴的なデザイン要素が左ダッシュ線。省略するとブランドらしさが失われる |
| **Fix** | 大見出しは必ず `addH1(slide, text)` を使う。直接テキスト追加は禁止 |

### 4-3. 表紙のテキストを左寄せにする

| 項目 | 内容 |
|------|------|
| **NG** | 表紙のタイトル・宛名に `align: 'left'` や `align` 未指定（デフォルト左寄せ）を使う |
| **Why** | 表紙の全テキストは水平中央配置（`align: 'center'`）が絶対ルール。左寄せにすると表紙のバランスが崩れる |
| **Fix** | 表紙内のすべてのテキストに `align: 'center'` を明示する |

### 4-4. フッターを省略すべきでないスライドで省略する

| 項目 | 内容 |
|------|------|
| **NG** | 本文スライド・目次スライドにフッターがない |
| **Why** | フッター（軸線 + © NONAME Produce Inc. + ページ番号）は本文スライドの必須要素。省略するとプロフェッショナリズムが失われる |
| **Fix** | 本文スライド・目次スライドの末尾で必ず `addFooter(slide, pageNum)` を呼ぶ。表紙・中表紙・エンドのみ省略する |

### 4-5. フッターを表示すべきでないスライドで表示する

| 項目 | 内容 |
|------|------|
| **NG** | 表紙スライド／中表紙／エンドスライドにフッターやページ番号を追加する |
| **Why** | 表紙・中表紙・エンドスライドにフッターを表示すると、デザインのクリーンさが損なわれる。中表紙はセクション区切り役なのでフッター・ページ番号は不要 |
| **Fix** | 表紙・中表紙・エンドスライドでは `addFooter` を呼ばない |

## 5. 企業名違反

### 5-1. NG表記を使う

| NG表記 | 正しい表記 | 理由 |
|--------|----------|------|
| `N2P` | `n2p` | 大文字混在は会社が定義した表記と異なる |
| `株式会社 n2p` | `株式会社 NONAME Produce` | 法人名に小文字 `n2p` は使用不可 |
| `nonameproduce` | `NONAME Produce` | 全小文字・スペースなしは禁止 |
| `noname produce` | `NONAME Produce` | 全小文字は禁止 |
| `株式会社 N2P` | `株式会社 NONAME Produce` | 大文字NGおよび法人名に不可 |

### 5-2. 初出で略称のみ使う

| 項目 | 内容 |
|------|------|
| **NG** | 文書の最初から `n2p` だけで呼称する |
| **Why** | クライアントが略称の意味を把握できない場合がある |
| **Fix** | 初出は `NONAME Produce（以下 n2p）` または `株式会社 NONAME Produce（以下 n2p）` の形式を使う |

### 5-3. コード例・コメントにNG表記を混入する

| 項目 | 内容 |
|------|------|
| **NG** | `slide.addText('nonameproduce', ...)` / コメントに `// N2P の資料` と書く |
| **Why** | コード・ドキュメント内でも企業名表記ルールは適用される |
| **Fix** | コード内でも `'NONAME Produce'` / `'n2p'` / `'株式会社 NONAME Produce'` の正式表記を使う |

## 6. 強調違反

### 6-1. イエロー使用が全体面積の10%を超える

（1-4 カラー違反 参照。カテゴリ横断の重要パターンのため再掲）

| 項目 | 内容 |
|------|------|
| **NG** | 1スライドの主要背景・大きなボックス全体をイエローにする |
| **Fix** | キーワード単位のハイライトに限定。1スライドにつき2〜4箇所が目安 |

### 6-2. 太字と色強調を同時多用する

| 項目 | 内容 |
|------|------|
| **NG** | 同一テキストに `bold: true` + `color: yellowLight` + アンダーラインを同時設定する / 強調が多すぎて何が本当に重要かわからなくなる |
| **Why** | 強調は「最も伝えたい1点」に集中することで効果を発揮する。過剰な強調は効果を打ち消す |
| **Fix** | 強調は1スライドにつき「太字のみ」または「イエロー背景のみ」どちらか1種類を1〜2箇所に絞る |

### 6-3. 強調にリンク色（#4285F4）を流用する

| 項目 | 内容 |
|------|------|
| **NG** | 強調したいキーワードを青（`#4285F4`）で着色する |
| **Why** | `#4285F4` はリンク色として定義されている。強調目的で使うと「リンクに見えるが実はテキスト」という混乱を招く |
| **Fix** | テキスト強調はイエロー背景（`#F4F400`）か太字のみ。青はリンクにのみ使用 |

## 7. 図形・矢印違反

### 7-1. 装飾的な太い矢印・ポップな矢印を使う

| 項目 | 内容 |
|------|------|
| **NG** | 塗りつぶし矢印図形（`blockArrow`）/ 立体的な矢印 / カラフルな矢印を使う |
| **Why** | n2p のデザインコンセプト「シンプルで洗練された」に反する。フロー図は線 + 小三角形で表現する |
| **Fix** | `slide.addShape('line', { ..., line: { endArrowType: 'triangle' } })` で細い矢印線を使う。線太さ 1pt、色 `#CCCCCC` または `#111111` |

### 7-2. 異質な図形を使う

| 項目 | 内容 |
|------|------|
| **NG** | 星形・ハート・吹き出し（スピーチバブル）・リボンバナー などポップな図形を使う |
| **Why** | n2p のスライドで使える図形は「長方形 / 角丸長方形 / 楕円 / 線」が基本。異質な形はブランドを逸脱する |
| **Fix** | 基本図形のみを使う。アイコンは画像ファイル（PNG）として配置する |

### 7-3. 色付き枠線を多用する

| 項目 | 内容 |
|------|------|
| **NG** | 赤枠・青枠・カラフルな太い枠線でボックスを強調する |
| **Why** | n2p の枠線は `#111111`（1pt）または `#CCCCCC`（0.5pt）が標準。色付き枠線は雑然とした印象を与える |
| **Fix** | ボックスの差別化は「塗り色の違い」（白 vs ライトグレー vs ダークグレー）で行う。枠線は極力シンプルに |

## 8. 素材違反

### 8-1. いらすとやのイラストを使う

| 項目 | 内容 |
|------|------|
| **NG** | いらすとや（irasutoya.com）のフリーイラストをスライドに配置する |
| **Why** | いらすとやのイラストは「ポップで親しみやすい」スタイルであり、n2p の「シンプルで洗練された」ブランドと相容れない。また、著名なフリー素材のため「手軽さ・安さ」の印象を与える |
| **Fix** | アイソメトリックなビジネス系イラスト・モノクロ線画アイコン・高品質な写真を使用する |

### 8-2. 透かし入り・著作権保護された画像を使う

| 項目 | 内容 |
|------|------|
| **NG** | ウォーターマーク（透かし文字）が入った素材サイトの画像をそのまま使う |
| **Why** | 著作権侵害リスク + プロフェッショナルなクオリティが失われる |
| **Fix** | 購入済みライセンス画像または著作権フリー素材（Unsplash / Pixabay 等、商用利用可のもの）を使用する |

### 8-3. 低画質・ピクセル化した画像を使う

| 項目 | 内容 |
|------|------|
| **NG** | 解像度が低く、拡大するとピクセルが見える画像を配置する |
| **Why** | 低画質画像は資料全体の品質を下げ、クライアントへの悪印象につながる |
| **Fix** | 画像は最低でも 1280px 幅以上のものを使用する。スライドに配置する際はサイズを原寸以下にとどめる |

### 8-4. 不自然なポーズ・過剰にポーズドな写真を使う

| 項目 | 内容 |
|------|------|
| **NG** | 白背景でガッツポーズするビジネスパーソン / 指差しポーズのチームの集合写真など |
| **Why** | 過剰にポーズドな写真はリアリティを失い、逆に「安っぽいストックフォト」の印象を与える |
| **Fix** | 自然なシチュエーション・ドキュメンタリー風の写真を使用する。人物が映る場合も「仕事中」「日常的な場面」を選ぶ |

## クイックリファレンス：一発でわかるNG vs OK

| カテゴリ | NG例 | OK例 |
|---------|------|------|
| 黒 | `'212121'` / `'000000'` | `'111111'` |
| 白背景 | `'FFFFFF'` | `'FCFCFC'` |
| 本文色 | `'333333'` / `'555555'` | `'434343'` |
| 行間 | `1.0` / `1.5` | `1.15` |
| 大見出し | Bold忘れ / ダッシュ線なし | `addH1()` を使用 |
| フォント | Meiryo / Yu Gothic | Noto Sans JP |
| 企業名 | `N2P` / `nonameproduce` | `NONAME Produce` / `n2p` |
| ロゴ透明度 | `transparency: 30`（本文スライド） | `addLogoBlack()` / `addLogoWhite()` |
| 矢印 | 塗りつぶし太矢印 | 細い線 + 小三角 1pt |
| 素材 | いらすとや / 透かし入り画像 | 高品質フォト / ビジネス系アイコン |
