## 2. イエロー2段階使用ルール

### 濃イエロー: `#E8E800`（小面積専用）
- **用途**: 文字のハイライト、バッジ、ピルラベル、アイコン補助色
- **面積**: 1スライド内でテキスト2〜3語分程度の小面積に限定
- **背景**: 黒（`#111111`）テキストと組み合わせること

### 薄イエロー: `#F4F400`（大面積専用）
- **用途**: 強調帯、マーカー効果、中表紙アクセント背景
- **面積**: 大面積可（ただし後述の10%ルール厳守）
- **背景**: 黒（`#111111`）テキストと組み合わせること

### Yellow 使用量上限: **全体の10%以下**
- スライド全体の面積に対し、イエロー（濃・薄合計）が占める割合を10%以内に抑える
- 10%超えの場合はグレー系に置き換える
- 表紙タイトル下線・本文ハイライト程度の使用量が上限の目安

## 3. グレー4段階の使い分け

```
#111111 ← 見出し・強調（最も暗い）
 ↓
#434343 ← 本文テキスト（body_gray）
 ↓
#676A6D ← サブテキスト・キャプション (dark_gray)
 ↓
#929699 ← 中位アクセント（mid_gray）
 ↓
#E6EBED ← 薄背景・差し色（lite_gray）
 ↓
#CCCCCC ← フッター軸線（divider_gray）
 ↓
#999999 ← フッター文字（footer_gray）
```

---

## 4. 配色比率原則

```
白（#FCFCFC） > 黒（#111111） > グレー（4段階） > イエロー（10%以下）
```

- **背景**: `#FCFCFC`（本文スライド）、`#E6EBED`（中表紙・区切りスライド）
- **テキスト主力**: `#111111`（見出し）、`#434343`（本文）
- **補助色**: グレー4段階をレイヤーとして使用
- **アクセント**: イエローは全体の10%以内に厳守

---

## 5. アクセントカラー（案件固有色）使用ルール

案件ごとにクライアントブランドカラーを使用する場合がある。その際のルール:

- **使用箇所の制限**: 表紙のタイトルエリア・タイトル下線のみに限定
- **本文スライドへの展開禁止**: 案件固有色をn2pブランドカラーの代替として使用しない
- **ロゴとの組合せ確認**: 案件固有色と n2p ロゴのコントラストを必ず確認（後述の基準参照）
- **グラデーション禁止**: 案件固有色をグラデーション化しない

---

## 6. 対背景コントラスト基準

### ロゴ配置時の背景色基準
| ロゴ種 | 使用可能な背景の明度 | 具体的HEX目安 |
|---|---|---|
| 黒ロゴ（symbol_black.png） | 明度 #CCCCCC 以上（明るい背景） | `#CCCCCC`〜`#FFFFFF` |
| 白ロゴ（symbol_white.png） | 暗度 #959595 以下（暗い背景） | `#000000`〜`#959595` |

### テキストコントラスト最低基準（WCAG AA準拠）
| テキストサイズ | 最低比率 |
|---|---|
| 小テキスト（< 18pt または < 14pt Bold） | 4.5:1 |
| 大テキスト（≥ 18pt または ≥ 14pt Bold） | 3.0:1 |
| 装飾テキスト／ロゴ | なし（ただし視認性確保） |

## 8. pptxgenjs カラー定数定義例

```javascript
// n2p ブランドカラー定数
// 注意: pptxgenjs では HEX を "#" なしの6桁文字列で指定する
const N2P_COLORS = {
  // メインカラー
  black:       '111111',  // 主見出し・フッター線・ロゴ黒（#212121は使用禁止）
  white:       'FCFCFC',  // 背景白（純白FFFFFFは使わない）

  // グレー4段階
  darkGray:    '676A6D',  // サブテキスト・強めアクセント
  midGray:     '929699',  // 中位アクセント
  liteGray:    'E6EBED',  // 薄背景・差し色
  bodyGray:    '434343',  // 本文テキスト

  // フッター系
  footerGray:  '999999',  // フッター文字
  dividerGray: 'CCCCCC',  // フッター軸線

  // イエロー（使用量10%以下厳守）
  yellowDark:  'E8E800',  // 小面積強調用
  yellowLight: 'F4F400',  // 大面積強調用

  // リンク系
  linkBlue:    '4285F4',  // リンク色
  teal:        '0097A7',  // ハイパーリンク色

  // 特殊用途
  corpHeader:  '1B2A4A',  // 会社概要ヘッダー背景（ダークネイビー）
};

// 使用例
slide.addText('見出しテキスト', {
  color: N2P_COLORS.black,
  fontFace: 'Noto Sans JP',
  fontSize: 16,
  bold: true,
});

slide.addText('本文テキスト', {
  color: N2P_COLORS.bodyGray,
  fontFace: 'Noto Sans JP',
  fontSize: 11,
});

// フッター軸線
slide.addShape(pptx.ShapeType.line, {
  x: 0.28, y: 5.28, w: 9.44, h: 0,
  line: { color: N2P_COLORS.dividerGray, width: 0.5 },
});

// フッターコピーライト
slide.addText('© NONAME Produce Inc.', {
  x: 0.28, y: 5.30, w: 4, h: 0.25,
  color: N2P_COLORS.footerGray,
  fontFace: 'Noto Sans JP',
  fontSize: 8,
});

// イエローハイライト（小面積）
slide.addShape(pptx.ShapeType.rect, {
  x: 1.0, y: 1.5, w: 1.2, h: 0.3,
  fill: { color: N2P_COLORS.yellowDark },
  line: { color: N2P_COLORS.yellowDark },
});
```

## 9. 色使用チェックリスト

- [ ] 黒は `#111111` のみ使用（`#212121` が混入していないか確認）
- [ ] 背景白は `#FCFCFC` を使用（`#FFFFFF` は不使用）
- [ ] イエローの占有面積が全体の10%以下か確認
- [ ] イエロー上のテキストは黒（`#111111`）のみか確認
- [ ] ロゴ背景の明度が基準（黒ロゴ→`#CCCCCC`以上、白ロゴ→`#959595`以下）を満たすか確認
- [ ] 案件固有色は表紙タイトルエリアのみに限定されているか確認
