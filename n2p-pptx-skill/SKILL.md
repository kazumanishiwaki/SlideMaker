# n2p提案資料デザインスキル

## Purpose

NONAME Produce（以下 n2p）のブランドガイドライン（VI 2021.10.27）に完全準拠した PPTX 提案資料を作成するためのスキル。

**pptxスキルとの役割分担:**
- **pptxスキル** — pptxgenjs の技術仕様・API・ファイル生成・QA手順
- **このスキル** — n2p のデザインルール（色・フォント・ロゴ・余白・フッター・企業名表記）

pptxスキルが提示する「Design Ideas」のカラーパレットやフォント推奨は **無視** し、このスキルのルールを優先する。

---

## Triggering Signals

以下のいずれかに当てはまる場合、このスキルを使う:

- 「提案資料を作って」「PPTXを作成」「スライドを設計・作成」
- 「企画書」「デッキ」「プレゼン資料」「キャンペーン提案書」
- n2pのブランド・ガイドライン準拠が必須と明示されている
- 見出し色 `#111111`、本文色 `#434343`、アクセント `#E8E800`/`#F4F400` が指定される
- ロゴ配置・フッター・マージン規定を伴う資料制作

---

## Hard Rules

絶対遵守。例外なし。

1. **黒は `#111111` のみ** — `#212121`・`#000000`・`#1A1A1A` など類似黒は一切使わない。VIガイドライン違反。見出し・フッター線・ロゴ黒はすべて `#111111`。

2. **白は `#FCFCFC` のみ** — 純白 `#FFFFFF` は使わない。背景白はすべて `#FCFCFC`。

3. **本文テキストは `#434343` / 11pt / 行間1.15** — サイズ・色・行間は固定。変更は管理職承認レベルの判断が必要。

4. **アクセントカラーはイエロー2段のみ、使用量10%以下** — 小面積強調は `#E8E800`（濃）、大面積マーカーは `#F4F400`（薄）。他色のアクセントは表紙タイトル・重要強調に限定し、常に1案件1色まで。

5. **ロゴは背景輝度で白黒を使い分ける** — 明度 `#CCCCCC` 以上の明るい背景 → `symbol_black.png`（黒ロゴ）。明度 `#959595` 以下の暗い背景 → `symbol_white.png`（白ロゴ）。中間グレーは白ロゴを優先。

6. **ロゴ隔離エリアはロゴ高さの50%** — ロゴ周囲すべての方向にロゴ高さの50%以上の空白を確保。Web最小32px、印刷最小10mm。

7. **マージンは上下左右0.5cm厳守** — コンテンツエリアは x:0.197"〜9.803"、y:0.197"〜5.428"（フッター上端まで）。スライドサイズは16:9 (10×5.625 inch)。

8. **フッターは本文スライドのみ** — 表紙・中表紙・エンドスライドにはフッターなし。本文スライドは軸線(y:5.28, x:0.28〜9.72, 0.5pt `#CCCCCC`) + © NONAME Produce Inc.（x:0.28, y:5.30, 8pt `#999999`）+ ページ番号（x:9.20, y:5.30, w:0.5, 9pt `#999999`, 右寄せ）を必須配置。

9. **大見出し（h1）の左に1px黒ダッシュ線** — 色 `#111111`、高さ0.45in、太さ1pt。本文スライドの大見出しすべてに適用。

10. **企業名表記ルールを厳守** — OK: `NONAME Produce` / `n2p` / `株式会社 NONAME Produce`。NG: `nonameproduce` / `N2P` / `noname produce` / `株式会社 n2p` / `株式会社 N2P`。コード例・コメント・スライドテキストすべてで禁止。

11. **フォントは Noto Sans JP + Helvetica Neue** — Web/PPTX実装は Noto Sans JP（Light/Regular/Bold）+ Helvetica Neue。印刷合成時は中ゴシック BBB + Helvetica（105%スケール）を注記する。

12. **数字・英数字はすべて半角** — ページ番号・日付・金額・英語テキストはすべて半角。全角数字は禁止。

## Workflow

### Step 1 — pptxスキルを先に確認する
pptxgenjs の技術ガイド（pptxgenjs.md / editing.md）を読む。ファイル生成・スライド追加・図形・テキストボックスのAPIを把握する。

### Step 2 — このスキルのリファレンスを読む
`references/design-rules.md`（フォント・カラー・余白・ロゴ・フッター基礎仕様）→ `references/slide-patterns.md`（スライドパターン実装集）の順に読む。色値・座標・関数定義を記憶してから実装に入る。

### Step 3 — スライド構成を決める
提案資料の標準構造:

```
1. 表紙（#E6EBED背景、中央配置、symbol_white透かし右下）
2. 目次（左右分割レイアウト）
3. [中表紙] セクション1（#676A6D背景、symbol_white右上）
4〜N. 本文スライド群（#FCFCFC背景、symbol_black右上、フッター有）
N+1. [中表紙] セクション2
...
末尾-2. 会社概要（ダークヘッダー）
末尾-1. 組織図
末尾. エンドスライド（symbol_black中央配置、フッターなし）
```

### Step 4 — pptxgenjsで実装する
`references/helpers.md` のヘルパー関数（`addLogoBlack()` / `addLogoWhite()` / `addFooter()` / `addH1()` 等）を使って実装。座標は `references/design-rules.md` の導出式付き数値を参照。

### Step 5 — QAチェックリストで検証する
下記「Verification Checklist」の全項目を確認してから完了とする。1項目でも未確認のまま「完了」と報告しない。

## Anti-patterns

- **`#212121`・`#000000` を黒として使う** — VIガイドライン違反。黒は必ず `#111111`。既存コードのサーチ&リプレースで除去する。

- **フッターを全スライドに配置する** — 表紙・中表紙・エンドスライドはフッターなし。スライドタイプを判定してから `addFooter()` を呼ぶ。

- **symbol_white を白背景に置く** — 白ロゴは白背景では不可視。背景輝度を必ず確認してからロゴ種別を決める。

- **企業名を `N2P`・`nonameproduce` と書く** — スライドの表示テキスト・コードコメント・ユーザーに見える文字列で禁止。`n2p` または `NONAME Produce` を使う。技術的な定数名（例: `N2P_COLORS`）は内部識別子として許容する。

- **アクセントカラーを複数色・10%超で使う** — イエロー2色以外のアクセントを使う場合は表紙タイトル等に限定。面積10%超は禁止。

- **pptxスキルのデフォルトカラーをそのまま適用する** — pptxスキルの "Design Ideas" は n2p 非準拠。必ず上書きする。

- **全角数字・全角英字をスライドテキストに入れる** — ページ番号・日付・金額はすべて半角。フォント混在も視認性を損なう。

## Common Mistakes

| 症状 | 原因 | 対処 |
|-----|------|------|
| ロゴが白背景に溶け込む | `symbol_white.png` を明るい背景に配置 | 背景輝度を確認し `symbol_black.png` に差し替える |
| 見出し色が微妙にズレている | `#212121`・`#1A1A1A` 等を使用 | 全箇所を `#111111` に一括置換 |
| フッターが中表紙にも表示される | スライドタイプ分岐なしに `addFooter()` を全スライドに適用 | 中表紙・表紙・エンドスライドでは `addFooter()` を呼ばない |
| ページ番号が全角 | 文字列結合で全角混入 | テンプレートリテラルを半角数字で統一。`String(pageNum)` を使う |
| アクセントカラーが派手すぎる | イエロー `#F4F400` をスライド面積の30%超に使用 | イエロー使用面積を10%以下に削減。小面積なら `#E8E800` へ切替 |
| 本文テキストが `#333333` や `12pt` | pptxスキルのデフォルト値が混入 | `#434343` / `11pt` / 行間1.15 に修正 |
| ロゴ周囲に余白がない | 隔離エリア未確保 | ロゴ高さの50%以上の空白を四方に確保。隣接要素を退ける |
| 企業名が `N2P` 表記 | 略称として誤用 | スライドテキスト・コードコメントを `n2p` に修正 |
| フッター軸線の色が `#999999` | `#CCCCCC` との混同 | 軸線は `#CCCCCC` 0.5pt。フッター文字は `#999999` と別管理 |

## Verification Checklist

完了前に全項目を確認する。1つでもチェックできない場合は完了扱いにしない。

- [ ] 黒色がすべて `#111111` — `#212121` / `#000000` が残っていないか検索して確認
- [ ] 白色がすべて `#FCFCFC` — `#FFFFFF` が背景に使われていないか確認
- [ ] 本文テキストが `#434343` / 11pt / 行間1.15 で統一されている
- [ ] アクセントカラー（`#E8E800` / `#F4F400`）の使用面積が全体の10%以下
- [ ] `symbol_black.png` が明るい背景に、`symbol_white.png` が暗い背景に配置されている
- [ ] ロゴ周囲の隔離エリアがロゴ高さの50%以上確保されている
- [ ] マージンが上下左右0.5cm（≈0.197inch）を守っている
- [ ] フッター（軸線 + © + ページ番号）が本文スライドのみに存在する
- [ ] 表紙・中表紙・エンドスライドにフッターがない
- [ ] 大見出し（h1）の左に1pt `#111111` のダッシュ線（高さ0.45in）がある
- [ ] ページ番号がすべて半角数字で昇順に連番されている
- [ ] 企業名表記がすべて `NONAME Produce` または `n2p` （NG表記が混入していない）
- [ ] フォントが Noto Sans JP（+Helvetica Neue）で統一されている
- [ ] スライドサイズが 10×5.625 inch（16:9）になっている
- [ ] ロゴファイルパスが正しく（`assets/symbol_black.png` / `assets/symbol_white.png`）参照されている

## Notes

- **色のカスタマイズについて**: 企画の個性を出す際も、余白・ページ番号・フッターは必ず守る。案件固有のアクセントカラーを使う場合は表紙タイトル・重要強調に限定し、全体1色まで。
- **印刷用途**: Web/PPTX用は Noto Sans JP だが、印刷入稿時は中ゴシック BBB（日本語）+ Helvetica 105%スケール（欧文）の合成フォントを使用する旨を担当者に確認する。
- **参考PDF**: VI ガイドライン原本 `references/n2p_vi_guideline_211027.pdf`（色・ロゴ仕様の一次情報）。色値・ロゴルールに疑問が生じた場合は必ずPDFを参照する。
- **pptxスキルとの衝突**: 技術仕様（ファイル保存・スライド追加API）はpptxスキルに従い、デザイン仕様（色・フォント・余白・ロゴ）はこのスキルを優先する。
