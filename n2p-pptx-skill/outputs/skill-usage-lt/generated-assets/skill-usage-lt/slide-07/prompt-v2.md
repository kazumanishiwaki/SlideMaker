# Prompt v2

Slide: 7 - そこで Skill
Purpose: Show Skill as a simple reusable package without visual clutter.
Image type: concept diagram
Target ratio: 4:3

## Prompt

Create an extremely simple n2p proposal slide illustration on a pure white background.
Use only clean black linework, two light gray fills, and one tiny n2p yellow accent.
Flat, front-facing, minimal Japanese business proposal tone.

Composition: one large open folder/package in the center. Three small plain cards enter from the left. One simple monitor/document icon sits on the right. Use only three arrows total. No labels and no readable text.
The package should be the clear focus; remove small icons such as scales, code symbols, checklists, image thumbnails, robots, pens, and decorative cards.
Use no people, no shadows, no gradients, no perspective, no busy details.

Output: clean textless illustration, no border, white background, ready to place in a PPTX slide.
