# Prompt v2

Slide: 13 - 使う・見る・戻す
Purpose: Show the improvement loop in the simplest possible form.
Image type: workflow visual
Target ratio: 16:9

## Prompt

Create an extremely simple n2p proposal slide illustration on a pure white background.
Use only clean black linework, two light gray fills, and one tiny n2p yellow accent.
Flat, front-facing, minimal Japanese business proposal tone.

Composition: three large simple icons arranged in a triangle loop:
1. a small package/folder,
2. a document with a magnifying glass,
3. a checklist card.
Connect them with three clean curved arrows. No labels and no readable text.
Keep each icon simple, with large whitespace around it. Use the yellow accent on only one small checklist mark or one short arrow segment.
Use no people, no shadows, no gradients, no perspective, no extra documents, no decorative details.

Output: clean textless illustration, no border, white background, ready to place in a PPTX slide.
