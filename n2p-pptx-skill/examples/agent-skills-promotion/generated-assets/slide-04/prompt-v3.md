## Prompt

Create a flat n2p proposal slide illustration on a pure white background, wide 16:9. Use black and dark gray linework, simple gray fills, and very small n2p yellow accents only. Calm, minimal, business-oriented, suitable for a Japanese proposal deck.

Show a front-facing left-to-right visual transformation without any text: left, a flat front-facing generic laptop/screen representing a raw AI mock; center, a flat front-facing filter/checkpoint circle with a small yellow accent representing project understanding; right, a flat front-facing proposal screen with structured blocks and simple chart shapes. Use simple thin arrows and small particles moving through the filter.

No words, no letters, no numbers, no readable UI text. Leave all labels to be added later as editable PowerPoint text.

Strict style constraints: no shadows of any kind, no drop shadows, no cast shadows, no ground shadows, no perspective, no tilt, no skew, no angled screens, no isometric view, no 3D depth, no glossy surfaces, no gradients. Everything must be flat, front-facing, orthographic, and clean.

Avoid photorealistic people, stock-photo style, manga style, hand-drawn sketch style, neon colors, vivid gradients, glassmorphism, glowing blobs, busy backgrounds, clutter, fake detailed UI screenshots, and decorative elements that do not explain the slide. No border.
