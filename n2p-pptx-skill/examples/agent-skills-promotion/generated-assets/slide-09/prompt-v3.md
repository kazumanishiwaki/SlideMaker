## Prompt

Create a flat n2p proposal slide illustration on a pure white background, wide 16:9. Use black and dark gray linework, simple gray fills, and very small n2p yellow accents only. Calm, minimal, business-oriented, suitable for a Japanese proposal deck.

Show a front-facing transformation without any text: left side has a flat speech bubble containing abstract fragments and question-like marks, representing vague feedback; center has a flat yellow document/card as a conversion point; right side has three flat stacked rule cards with check marks, representing explicit shared rules. Use simple arrows and generous white space.

No words, no letters, no numbers, no readable UI text. Leave all labels to be added later as editable PowerPoint text.

Strict style constraints: no shadows of any kind, no drop shadows, no cast shadows, no ground shadows, no perspective, no tilt, no skew, no angled cards, no isometric view, no 3D depth, no glossy surfaces, no gradients. Everything must be flat, front-facing, orthographic, and clean.

Avoid photorealistic people, stock-photo style, manga style, hand-drawn sketch style, neon colors, vivid gradients, glassmorphism, glowing blobs, busy backgrounds, clutter, fake detailed UI screenshots, and decorative elements that do not explain the slide. No border.
