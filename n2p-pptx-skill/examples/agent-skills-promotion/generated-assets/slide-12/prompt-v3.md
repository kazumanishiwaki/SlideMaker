## Prompt

Create a flat n2p proposal slide illustration on a pure white background, wide 16:9. Use black and dark gray linework, simple gray fills, and very small n2p yellow accents only. Calm, minimal, business-oriented, suitable for a Japanese proposal deck.

Show a front-facing three-step workflow without any text: left, a flat repository folder icon; center, a flat rule document with a small yellow highlight; right, a flat AI request panel with a simple robot/icon and prompt field. Add two small flat optional branch cards below the rule document, connected with subtle dashed lines. Use thin arrows and clear spacing. Keep the height compact so it can sit inside a PPT slide without crowding title or footer areas.

No words, no letters, no numbers, no readable UI text. Leave all labels to be added later as editable PowerPoint text.

Strict style constraints: no shadows of any kind, no drop shadows, no cast shadows, no ground shadows, no perspective, no tilt, no skew, no angled panels, no isometric view, no 3D depth, no glossy surfaces, no gradients. Everything must be flat, front-facing, orthographic, and clean.

Avoid photorealistic people, stock-photo style, manga style, hand-drawn sketch style, neon colors, vivid gradients, glassmorphism, glowing blobs, busy backgrounds, clutter, fake detailed UI screenshots, and decorative elements that do not explain the slide. No border.
