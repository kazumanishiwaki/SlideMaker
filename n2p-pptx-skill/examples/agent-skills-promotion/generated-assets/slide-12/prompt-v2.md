## Prompt

Create a polished n2p proposal slide illustration on a pure white background, wide 16:9. Use black and dark gray linework, simple gray fills, and very small n2p yellow accents only. Calm, minimal, business-oriented, suitable for a Japanese proposal deck.

Show a clean three-step workflow without any text: left, a repository folder icon; center, a rule document with a small yellow highlight; right, an AI request panel with a simple robot/icon and prompt field. Add two small optional branch cards below the rule document, connected with subtle dashed lines. Use thin arrows, clear spacing, and a finished illustration style. Keep the height compact so it can sit inside a PPT slide without crowding title or footer areas.

No words, no letters, no numbers, no readable UI text. Leave all labels to be added later as editable PowerPoint text.

Avoid photorealistic people, stock-photo style, manga style, hand-drawn sketch style, neon colors, vivid gradients, glassmorphism, glowing blobs, excessive shadows, busy backgrounds, clutter, fake detailed UI screenshots, and decorative elements that do not explain the slide. No border.
