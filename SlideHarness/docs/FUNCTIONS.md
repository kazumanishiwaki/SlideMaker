| `statement` | 単一メッセージ | 主張、ラベル | テキストと図形を編集可能 |
| `title_body` | 本文 | 箇条書き | テキストを編集可能 |
| `title_body_callout` | 本文と強調枠 | 箇条書き、コールアウト | テキストと図形を編集可能 |
| `two_column_equal` | 2列整理 | 2列の見出しと本文 | テキストと図形を編集可能 |
| `three_column` | 3列整理 | 3列の見出しと本文 | テキストと図形を編集可能 |
| `card_grid_2x2` | カード一覧 | 3件から4件のカード | テキストと図形を編集可能 |
| `comparison` | 比較 | 2列の比較内容 | テキストと図形を編集可能 |
| `kpi_grid` | 指標表示 | 最大4件の指標 | テキストと図形を編集可能 |
| `native_bar_chart` | 棒グラフ | カテゴリ、系列、値、示唆 | PowerPointグラフを編集可能 |
| `native_chart` | 複数種類のグラフ | 種類、カテゴリ、系列、X値、Y値、示唆 | PowerPointグラフを編集可能 |
| `table` | 表 | 列、行 | PowerPoint表を編集可能 |
| `process` | 手順とフロー | 2件から5件のステップ | 図形、テキスト、接続線を編集可能 |
| `image_text` | 画像と説明 | 画像要求、見出し、本文 | 画像以外を編集可能 |
| `generated_visual` | 画像化したグラフまたはフロー | 画像要求、正確なラベルと値 | タイトルと要点は編集可能、図の内部は画像 |
| `closing_cta` | 締めと次の行動 | 本文、最大3件の行動 | テキストと図形を編集可能 |

## 対応済みネイティブグラフ

現行の `native_bar_chart` は互換性のため維持する。

グラフ種類は一つの `native_chart` レシピと `chart_type` で標準化する。

| Recipe ID | `chart_type` | 用途 |
|---|---|---|
| `native_chart` | `bar`、`column` | 項目間の量を比較する |
| `native_chart` | `stacked-bar`、`stacked-column` | 合計と内訳を比較する |
| `native_chart` | `line` | 時系列の変化を示す |
| `native_chart` | `area` | 時系列の量と累積傾向を示す |
| `native_chart` | `pie`、`doughnut` | 少数カテゴリの構成比を示す |
| `native_chart` | `scatter` | 2変数の関係と分布を示す |

## 後回しにする機能

- クラウドへの公開と共有URLの発行。
- 複数利用者による同時編集と権限管理。
- PowerPoint内でのリアルタイム共同編集。
- 生成したPPTXの自動配信と外部ストレージへの自動保存。
- ランの履歴画面、再開、キャンセル、削除。
- 外部公開時の認証、監査、レート制限。
- Microsoft PowerPoint実機による自動レンダー検証。
- 旧実装 `archive/v0.10/` の保守と機能追加。
