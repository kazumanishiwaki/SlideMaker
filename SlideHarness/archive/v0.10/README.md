# SlideHarness v0.10 archive

This directory preserves the retired implementation that preceded the current
greenfield `nextgen/` system.

Archived here:

- `server.mjs`, `public/`, and `src/project-store.mjs`
- `engine/` and its Python tests
- the previous `skill/` and schemas
- historical `docs/`, package placeholders, scripts, and demos
- the old environment example and dependency list

The archive is intentionally disconnected from root `package.json`,
`npm start`, and `npm test`. It remains recoverable for historical comparison,
but new fixes and features belong only in `nextgen/`.

`README-original.md` and `AGENTS.md` record the former operating contract.
