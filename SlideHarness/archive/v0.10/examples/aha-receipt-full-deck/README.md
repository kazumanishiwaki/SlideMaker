# Aha! レシート Lite Full Deck v0.9.0

MIRI CompanyテンプレートとAha! レシート Lite原稿を使った9ページGolden Sampleです。

```bash
python examples/aha-receipt-full-deck/build.py
```

処理では利用する元スライドだけを選択レンダリングし、全17ページの再レンダリングを避けます。

出力:

- `aha-receipt-lite-full-deck-v0.9.0.pptx`
- `aha-receipt-lite-full-deck-v0.9.0-montage.png`
- `output-qa.json`
- `deck-qa.json`
- `summary.json`
